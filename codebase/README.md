# Codebase — Prototype VLearn Mindmap Navigation

Thư mục chứa mã nguồn Prototype (gọi AI API thật ở quyết định trung tâm).

- `frontend/`: Giao diện LMS giả lập hiển thị Slide + Sơ đồ cây Mindmap (Mermaid.js).
- `backend/`: Gọi Gemini API thật để phân tích slide và trích xuất cấu trúc Mindmap JSON.
